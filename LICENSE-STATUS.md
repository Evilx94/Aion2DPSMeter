# License status

A final project license has not yet been selected for this project.
It does not claim exclusive ownership of third-party components or data.
Existing source credits, the reference notice and the reference license text
are retained.

The runtime does not import an analyzer project or another meter checkout.
However, development used existing open-source meter implementations,
reference-informed protocol knowledge and own recordings. This is not a
clean-room claim. A different language, new architecture or local catalog
layout does not by itself establish a change in applicable conditions.

The local catalogs combine sourced game-data labels with own observations,
extensions and explicit confirmations. Detailed source history remains in the developer evidence records. These files are not described as fully independent replacement
tables. Consolidating or checking the records does not remove that history.

The earlier GPL port, its original notices and recordings remain outside
this separate project. Python, Scapy, PySide6 and Npcap retain their
respective terms; no interpreter, library binary or driver installer is
distributed here.
