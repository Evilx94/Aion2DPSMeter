# Source provenance

The UI, overlays, settings and live meter structure were developed for this
Python project. The development process also used existing open-source meter
implementations and locally recorded protocol evidence. This is not a
clean-room claim. Consolidating the catalogs does not change their provenance.

The runtime imports no analyzer project or reference checkout. Detailed source claims, original hashes, conflicting labels and own
confirmations are retained separately in the developer edition. Runtime
catalogs contain the operational mappings; attribution is centralised in the
third-party notices and retained license texts.
The source projects and existing notices are listed in THIRD-PARTY-NOTICES.md.

The developer edition retains tests and evidence tools. The public package
omits these, private recordings, actual party-roster fixtures, developer paths
and internal investigation reports. No full captures are bundled.

Python, Scapy, PySide6 and Npcap retain their respective terms. No interpreter,
third-party library binary, Npcap installer or external meter binary is shipped.

Catalog work includes our own observed IDs, controlled Bolt rune/charge
tests, HP-balance-backed periodic classifications and further observed
relationships. The data were checked, corrected and extended where evidence
was available. Not every sourced label has an independent name proof.
